# cpu

ブログ記事「CPUと演算・制御」で使うコードです。

## bits.c

型とポインタのサイズを表示します。ポインタのサイズから、64ビット環境かどうかがわかります。

```
cd cpu
gcc -O2 -o bits bits.c
./bits
```

## cores.c

同じ量の計算を、1つのスレッドで行う場合と、コアの数だけスレッドに分けて行う場合で、かかった時間を比べます。

```
gcc -O2 -pthread -o cores cores.c
./cores        # 使えるコアの数で実行
./cores 4      # スレッド数を指定して実行
```

- 結果は環境（PC、Codespacesなど）によって変わります。
- コアが1つしかない環境では、比較はできません。
