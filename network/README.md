# network

記事：[ネットワーク](https://pc-labo.online/2023/09/01/network/)

この記事は、コマンドだけで体験できます。コードファイルはありません。

## 体験1：ポート番号の対応表を見る

```bash
grep -E '^(ftp|ssh|smtp|http|pop3|https)[[:space:]]' /etc/services
```

サービス名とポート番号の対応が表示されます。

## 体験2：自分でサーバーを動かして、ポートを開く

**ターミナル1**で、Webサーバーを起動します。

```bash
python3 -m http.server 8000
```

**ターミナル2**（もう1つ開く）で、次を実行します。

```bash
ss -tln
curl -I http://localhost:8000
```

- `ss -tln`：待ち受け中（LISTEN）のポートの一覧。8000番が表示されます
- `curl -I`：HTTPで8000番のサーバーに話しかけ、応答のヘッダーを表示します

確認が終わったら、ターミナル1で `Ctrl + C` を押して、サーバーを止めます。

## 補足

- 80番を使わず8000番にしたのは、1023番以下は、通常は管理者権限が必要なためです
- Codespacesでは、ポートに関する通知が出ることがありますが、無視してかまいません
